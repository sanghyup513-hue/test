stderr 내용이 핵심입니다. exit code 2는 make 실패라는 사실만 말해주고, 원인은 저 파일에만 있습니다.

MLPERF_GPU_LIST가 나오면

며칠 전 제가 넣었다가 실패해서 원복했던 패치입니다. 405B가 4장에서 성공했던 시점에는 없었습니다. 원복이 덜 됐거나 중복 적용된 상태입니다.

백업이 있으면 그게 가장 확실합니다.

bash
ls -la scaleout/run_scaleout.sh.orig /tmp/rs.bak /tmp/run_scaleout.sh.bak 2>/dev/null

.orig가 있으면 그걸로 되돌리고 mpi_mode 패치만 다시 적용하세요.

bash
cd /data/lsh/inference_results_v6.0/closed/NVIDIA
cp scaleout/run_scaleout.sh /tmp/rs-broken-$(date +%H%M).sh
cp scaleout/run_scaleout.sh.orig scaleout/run_scaleout.sh
sed -i 's|run_args="\$run_args --mpi_mode=leader"|run_args="$run_args --mpi_mode=legacy"|g' scaleout/run_scaleout.sh
bash -n scaleout/run_scaleout.sh && echo "문법 OK"
grep -n 'MLPERF_GPU_LIST\|mpi_mode' scaleout/run_scaleout.sh

MLPERF_GPU_LIST가 사라지고 mpi_mode=legacy만 남아야 합니다.

백업이 없으면

repo에서 원본만 다시 받아 mpi_mode만 패치하는 방법이 있습니다.

bash
cd /data/lsh/inference_results_v6.0
git checkout -- closed/NVIDIA/scaleout/run_scaleout.sh 2>/dev/null \
  || curl -sL -o /tmp/rs-fresh.sh \
     https://raw.githubusercontent.com/mlcommons/inference_results_v6.0/main/closed/NVIDIA/scaleout/run_scaleout.sh
[ -s /tmp/rs-fresh.sh ] && cp /tmp/rs-fresh.sh closed/NVIDIA/scaleout/run_scaleout.sh
cd closed/NVIDIA
sed -i 's|run_args="\$run_args --mpi_mode=leader"|run_args="$run_args --mpi_mode=legacy"|g' scaleout/run_scaleout.sh
bash -n scaleout/run_scaleout.sh && grep -n 'mpi_mode' scaleout/run_scaleout.sh
